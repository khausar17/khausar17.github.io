EduTutor — Multi-Agent AI Tutoring System

LLM · Agentic AI · RAG · SPM Additional Mathematics

An end-to-end tutoring pipeline, not a single chatbot

  • Multi-agent architecture — Router, Tutor, and Hint agents — for personalized Add Maths learning at SPM level.
  • Retrieval-Augmented Generation over curriculum-aligned materials using Qdrant, improving relevance and factual accuracy.
  • Local AI infrastructure via Docker and Ollama for efficient, self-hosted model execution.
  • Workflow orchestration with n8n, with cloud model access bridged through Ngrok.
  • Custom backend APIs and math-reasoning tools for solution explanations and adaptive hints.
  • PostgreSQL-based conversational memory to keep learning context across sessions.
  • Responsive front end (HTML/CSS/JS) built for the student's actual learning experience.
